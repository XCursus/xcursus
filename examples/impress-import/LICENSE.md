# impress.js import example

`deck.html`, `images/ring.png` and `images/axes.svg` are original files written for XCursus on 2 November 2026 and dedicated to the public domain under CC0-1.0. The deck uses the markup conventions of impress.js 2.0.0 (MIT) but contains no impress.js code: `js/impress.js` and `css/deck.css` are referenced on purpose and not included, to show that the importer never loads them.
